# Electricity — เวอร์ชันหน้าต่างเลือกแถวและส่งออก CSV

เวอร์ชันนี้แยกจาก electricity_project เดิม ใช้สำเนาฐานข้อมูลและไฟล์ข้อมูลของตัวเอง ไม่แก้โค้ดหรือฐานของเวอร์ชันเดิม

## เปิดโปรแกรม

ต้องมี Python 3.9 ขึ้นไปพร้อม sqlite3 และ Tkinter ในชุดติดตั้ง Python ไม่ต้องมี DB Browser ไม่ใช้แพ็กเกจจาก pip และใช้งานออฟไลน์ได้

1. ดาวน์โหลดโฟลเดอร์ electricity_project_gui ทั้งชุดและแตก ZIP ก่อน
2. เปิด Terminal ในโฟลเดอร์นี้
3. รัน:

```powershell
python gui.py
```

หากเครื่องใช้คำสั่ง py ให้รัน py gui.py แทน

ตรวจว่าเครื่องมีหน้าต่าง Tkinter ได้ด้วย:

```powershell
python -m tkinter
```

คำสั่งนี้ควรเปิดหน้าต่างทดสอบ ถ้า Python ของเครื่องนั้นไม่มี Tkinter/Tcl/Tk ต้องเพิ่มส่วน Tcl/Tk ของชุดติดตั้ง Python ก่อน การมี Python อย่างเดียวไม่ได้รับประกันว่า Python ทุกรุ่นติดตั้งส่วนหน้าต่างมาด้วย

## วิธีเลือกและส่งออก

1. เลือกประเภทข้อมูลและปีที่ต้องการ all หมายถึงทั้งหมด หรือพิมพ์คำค้น ข้อมูลเริ่มต้นมี 110 แถว
2. คลิกแถวเพื่อเลือกหนึ่งรายการ
3. กด Ctrl ค้างแล้วคลิกเพื่อเพิ่ม/ยกเลิกแต่ละแถวที่ไม่ติดกัน
4. คลิกแถวต้นทาง แล้วกด Shift ค้างและคลิกแถวปลายทางเพื่อเลือกเป็นช่วง
5. คลิกแล้วลากขึ้น/ลงบนแถวเพื่อเลือกช่วงต่อเนื่องได้ด้วย เป็นการเลือกแถว ไม่ใช่การตีกรอบสี่เหลี่ยมบนพื้นที่ว่างแบบไอคอนใน File Explorer
6. Ctrl + A ขณะโฟกัสอยู่ในตาราง หรือปุ่ม “เลือกทั้งหมดที่แสดง” เลือกเฉพาะผลจากตัวกรองปัจจุบัน
7. ดูจำนวน “เลือก … แถว” แล้วกด “ส่งออกแถวที่เลือกเป็น CSV…”
8. เลือกชื่อและตำแหน่งไฟล์ ค่าเริ่มต้นอยู่ในโฟลเดอร์ exports ของเวอร์ชันนี้

คลิกชื่อหัวคอลัมน์เพื่อเรียงลำดับ คลิกอีกครั้งเพื่อสลับทิศทาง การเรียงยังคงรายการที่เลือกไว้ แต่การเปลี่ยนตัวกรองจะยกเลิกการเลือกเดิมเพื่อไม่ให้ส่งออกแถวที่ถูกซ่อน

รายละเอียดด้านล่างแสดงขอบเขต ตัวชี้วัด สถานะ และ URL ต้นทางของแถวที่โฟกัส

## CSV ที่ได้

- หนึ่งไฟล์รวมทุกแถวที่เลือก ตามลำดับในตาราง
- มีหัวตารางและครบ 12 คอลัมน์ของ CSV ต้นฉบับ แม้หน้าต่างแสดงเพียงคอลัมน์หลัก
- quantity ใช้ข้อความตัวเลขต้นฉบับจาก quantity_original ไม่แปลงทศนิยมผ่าน float ตอนส่งออก
- เข้ารหัส UTF-8 พร้อม BOM เพื่อให้เปิดข้อความใน Excel ได้สะดวก
- เลือกข้ามประเภทข้อมูลได้ ใช้ dataset_type คู่กับ id ระบุแถว เพราะ ID อาจซ้ำกันระหว่างตาราง
- CSV ที่ส่งออกเป็นผลเลือกข้อมูล ไม่ได้เปลี่ยนสถานะ reported ให้เป็น verified
- ไม่แก้ฐาน .db ระหว่างเปิดดูหรือส่งออก
- ป้องกันส่งออกทับไฟล์ภายใน electricity_project เดิม และป้องกันไฟล์ข้อมูล/โค้ดภายในเวอร์ชันใหม่นี้ หากบันทึกในโฟลเดอร์เวอร์ชันใหม่ให้ใช้ exports

## ไฟล์สำคัญ

| ไฟล์ | หน้าที่ |
| --- | --- |
| gui.py | หน้าต่างตาราง ตัวกรอง การเลือกแถว และปุ่มส่งออก |
| data_access.py | อ่านฐานแบบอ่านอย่างเดียว และเขียน CSV |
| electricity.db | สำเนาฐานที่มีข้อมูล 110 แถวและแหล่งอ้างอิง 5 แถว |
| build_db.py + schema.sql + data/ | สร้างฐานใหม่ของเวอร์ชันนี้จากสำเนา CSV |
| demo.py | โปรแกรม Terminal จากชุดต้นทาง ยังใช้ได้ |
| README_TERMINAL_TH.md | คู่มือการสร้างฐานและใช้ Terminal |
| tests/test_app.py | ทดสอบตัวกรอง การเลือก Ctrl/Shift/ลาก และผลส่งออก |

หากแก้ CSV ของเวอร์ชันนี้ ให้ปิดหน้าต่างก่อน แล้วรัน python build_db.py เพื่อสร้างฐานในเวอร์ชันนี้ใหม่ จากนั้นเปิด python gui.py อีกครั้ง ไม่ไปเปลี่ยนฐานในโฟลเดอร์เก่า
